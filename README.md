# Acecore

Public website redesign for Acecore — renewable energy technology.

## Repository structure

```text
acecore/
├── README.md
├── docs/
│   └── PRD.md         # Product requirements
├── frontend/          # Active React (Vite) application
└── backend/           # Reserved for future API work
```

## Getting started

```bash
cd frontend
npm install
npm run dev
```

## Scope

The current sprint is frontend-only. See [`docs/PRD.md`](docs/PRD.md) for product requirements and [`CURSOR.md`](CURSOR.md) for implementation standards.

Design references live in `frontend/figmaScreens/`.
